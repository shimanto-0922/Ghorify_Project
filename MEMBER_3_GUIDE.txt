Member 3 - interactions + search apps

How to use:
  1. git clone the team repo and open the folder
  2. git checkout -b member3_interactions_search
  3. Extract this zip INTO the repo folder (keep the folders as they are)
  4. Commit step by step (below), then: git push origin member3_interactions_search
  5. Open a Pull Request on GitHub and merge it

Order of merging: Member 1, then Member 2, then Member 3, then Member 4.
The site runs fully only after all four parts are merged.

Suggested commits:

  Commit 1: Add interactions app with Favourite and Comparison models
    git add interactions/__init__.py interactions/apps.py interactions/models.py interactions/migrations/
    git commit -m "Add interactions app with Favourite and Comparison models"

  Commit 2: Register interaction models in admin
    git add interactions/admin.py
    git commit -m "Register interaction models in admin"

  Commit 3: Add favourite and compare views
    git add interactions/views.py interactions/urls.py
    git commit -m "Add favourite and compare views"

  Commit 4: Add favourites and compare pages
    git add templates/interactions/
    git commit -m "Add favourites and compare pages"

  Commit 5: Add interaction tests
    git add interactions/tests.py
    git commit -m "Add interaction tests"

  Commit 6: Add search app and smart match form
    git add search/__init__.py search/apps.py search/migrations/ search/forms.py
    git commit -m "Add search app and smart match form"

  Commit 7: Add smart match engine
    git add search/matching.py
    git commit -m "Add smart match engine"

  Commit 8: Add smart match view and page
    git add search/views.py search/urls.py templates/search/
    git commit -m "Add smart match view and page"

  Commit 9: Add smart match tests
    git add search/tests.py
    git commit -m "Add smart match tests"
