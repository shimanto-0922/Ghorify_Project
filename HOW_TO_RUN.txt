Ghorify - kivabe chalabe
========================

Lagbe: Python 3.12 ba notun (install er somoy "Add Python to PATH" e tick), ar internet.


PROTHOMBAR (ekbar e korte hobe)
-------------------------------

1. Code nao (je kono ekta):
     git clone https://github.com/shimanto-0922/Ghorify_Project.git
     cd Ghorify_Project
   othoba GitHub e "Code" -> "Download ZIP", extract kore oi folder e terminal kholo.

2. Ei command gula ek ek kore chalao:
     python -m venv venv
     venv\Scripts\activate
     pip install -r requirements.txt
     python manage.py migrate
     python manage.py seed_demo
     python manage.py runserver

3. Browser e kholo:  http://127.0.0.1:8000

   (macOS/Linux e "venv\Scripts\activate" er bodole: source venv/bin/activate)
